# About this showcase

This repository is a deliberately sanitized portfolio representation of a private
financial-management application.

It is intended to show:

- the product problem being solved,
- the implemented feature scope,
- the high-level architecture,
- the technology stack,
- important financial/domain decisions,
- and the engineering/testing approach.

It intentionally does **not** mirror the private source tree or include real financial
data, private spreadsheets, databases, screenshots, logs, or production implementation
source.

The production repository remains private.
